Frequently Asked Questions

Effective March 5, 2026

Find quick answers about how BlackLight works, where to get it, privacy, accounts, and how businesses are added.

What is BlackLight?

BlackLight® is a discovery tool that helps you find Black-owned businesses while you search and shop online.

It works through a browser extension and companion web app that highlight Black-owned businesses directly within your search experience.

How does it work?

BlackLight® helps you discover Black-owned businesses while you search and shop online.

On desktop, install the BlackLight browser extension from the Chrome Web Store or the Microsoft Edge Add-ons store. Search the web as you normally would. When Black-owned businesses match your search, BlackLight highlights them directly in your results.

On mobile, simply visit blacklightapp.io to explore the BlackLight web app.

Isn’t there something like this already out there?

Directories exist, but you have to remember to visit them.

BlackLight integrates directly into your normal search experience so discovery happens automatically.

Where do I get BlackLight?

You can install the extension from the Chrome Web Store or the Microsoft Edge Add-ons store.

Which browsers does BlackLight work with?

BlackLight currently works with Chrome and Microsoft Edge.

Do I need an account?

No account is required for the browser extension.

An account is optional for the web app if you want features like favorites and recent history.

What about privacy?

The browser extension does not collect personal search information.

We do not sell personal information.

Why should I shop Black-owned?

Supporting Black-owned businesses helps expand economic opportunity and strengthen communities.

How are businesses added to BlackLight?

Businesses are identified using publicly available sources including government records and directories.

How will this help my business?

BlackLight helps consumers discover Black-owned businesses while they search online.
